# google-flow

Gera imagens (Nano Banana) e vídeos (Omni) no Google Flow pelo seu próprio Chrome, a partir de pedidos em português no Claude Code. No primeiro uso conecta a sua conta Google (você mesmo entra, o Claude nunca digita senha) e pergunta as suas preferências de estilo, idioma, música, legendas, formato e download em 1080p. Antes de cada geração mostra o custo em créditos e espera o seu ok; imagens não gastam crédito.

Instalar:

```
/plugin install google-flow --marketplace WanessaCelys/claude-google-flow
```

Requisitos: Claude Code, Python 3.10+, Google Chrome e uma conta com acesso ao Google Flow.

Instalação, custos, segurança e problemas comuns: veja o [README do repositório](../../README.md).

Projeto independente, não afiliado ao Google.
